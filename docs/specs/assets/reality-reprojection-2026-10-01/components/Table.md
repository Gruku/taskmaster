# Table

A data table with `table-layout: fixed`, Technical-voice headers (`tracking-ultra`) and `border-subtle` rows.

**Consumer provides:** `columns` (`{key, label, align, width}`), `rows` (objects keyed by column), and any of `striped`, `hoverable`, `compact`, `bordered`.

- Fixed widths so one long value never shifts a column. Numbers right-aligned, tabular.
