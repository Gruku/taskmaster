# CardGlow

An elevated card whose surface and border catch a signature light that follows the cursor — the system's quiet mischief in material.

**Consumer provides:** `children`, optional `header`. Mouse tracking is built in (sets `--glow-x`, `--glow-y`, `--glow-opacity`).

- Light uses `signature-glow` (surface) and `signature-glow-intense` (border) with Hourglass at `dur-standard` and Bell at `dur-micro`.
- Reserve for showcases — reactivity requires the user and must earn its place. Hidden in Survivalist.
- Recreated from the catalog spec (no source CSS shipped for it).
