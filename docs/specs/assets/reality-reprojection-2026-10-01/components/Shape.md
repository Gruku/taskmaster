# Shape

The semantic shape that travels with every status color, so meaning survives with hue stripped (Survivalist, D1, color-blind readers).

**Consumer provides:** `tone` (`success` ● · `warning` ▲ · `critical` ◆ · `info` ⓘ), optional `label`.

- Color is never the only signal: pair every semantic color with its shape, a word, or both.
- Shapes persist in the Survivalist theme when every hue collapses to value.
