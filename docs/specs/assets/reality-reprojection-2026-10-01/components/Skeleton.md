# Skeleton

A placeholder block (`ground-15`, `radius-sm`) swept by a Pendulum shimmer while content loads.

**Consumer provides:** `shape` (`text` · `heading` · `avatar` · `card` · `button` · `circle`), `width` for text (`full` · `medium` · `short`). Group with `skeleton-group` classes.

- Mirror the real layout so nothing jumps on arrival. Reduced motion: solid fill, no sweep.
