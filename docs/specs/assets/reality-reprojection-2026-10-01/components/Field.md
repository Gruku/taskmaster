# Field

The form group: label, control and help or error, spaced tight (`space-xs`) so they read as one unit, with wider gaps between groups.

**Consumer provides:** `label`, `htmlFor`, the control as `children` (Input, Select, Textarea), and `help` or `error`.

- Labels in the Narrator (small), help in Whisper, errors in `color-critical` with text — never color alone.
