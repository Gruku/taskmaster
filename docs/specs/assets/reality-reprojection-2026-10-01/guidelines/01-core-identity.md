# Core identity

*Layer 1 — what the system believes. Nothing in the other layers may contradict it; if something does, either that layer is wrong or this page needs an amendment.*

## Philosophy — five beliefs

1. **Constraints generate clarity.** Every element exists because it must. The limits of a medium — a terminal grid, a 128×64 OLED, a one-colour print run, a 1970s poster budget — are the pressure that makes every decision intentional. The system is not nostalgic for the past; it is nostalgic for *deliberateness*.
2. **Progressive revelation over information dumping.** The full depth is always available, never forced on arrival. Like a good map: the overview orients, you choose where to zoom. Clutter is not a density problem; it is a *structure* problem.
3. **Craftsmanship as respect.** A well-made thing communicates care for the person who holds it — a LEGO brick, a loading animation, a data table alike. The question is never "is this good enough?" but "does this show someone thought about the person on the other end?"
4. **The medium is a collaborator, not a container.** Screen, paper, embedded display, object, 3D space — each has a nature to work with. That includes AI: the system is the creative brief an AI generates against, a collaborator with its own nature.
5. **Design is alive until it stops changing.** New contexts should be absorbable without breaking what exists. The principles are durable; the expressions are not permanent.

## Character — the presence in the room

- **Physical weight** — through subtlety, not simulation. Grain, translucency and considered feedback make elements feel *placed* rather than floating. Not skeuomorphism: nothing pretends to be leather or wood.
- **Dramatic confidence** — bold type at scale, high-contrast silhouettes, saturated color deployed with surgical precision. It commits, but it is selective about when to raise its voice.
- **Warmth underneath precision** — blacks carry a faint tint, grays lean a degree toward amber. The structure is utilitarian; the temperature is *just barely* human. A tendency, not a mandate: a deliberately cold interface should be exactly that.
- **Quiet mischief** — small moments of play woven into the structure. Not random, not cute: a wink that says this was made by someone who enjoyed making it. A micro-animation that rewards attention.

## Tensions — the five dials

Each pair is a dial, set per project, per medium, per intent. Remove either side and the language collapses into something generic.

| Dial | One end | Other end | How the system turns it |
|---|---|---|---|
| **Monumental ↔ Intimate** | Type that fills the viewport | Details that reward close inspection | `declaration-hero` beside `narrator-whisper`; full saturation at display scale, value whispers at detail scale |
| **Utilitarian ↔ Sensorial** | Grids, clear hierarchy, nothing wasted | Texture, warmth, material that feels good in the hand | Fixed-layout tables *with* grain on the surfaces that earn it |
| **Constrained ↔ Expansive** | Rigid grids, limited palettes | Content vast and explorable on demand | The `survivalist` theme at one end; the full four-dimension palette at the other |
| **Technical ↔ Human** | Monospace, NASA-grade precision | Warm grays, humor, a maker's fingerprint | Technical voice for data, Narrator for people; temperature cools only when dialed toward Technical |
| **Confident ↔ Inviting** | Strong opinions, dramatic presence | Rewards curiosity, never intimidates | A big, clearly marked door (one primary action) and depth behind it |

**Moods** are named positions of all five dials at once. The system ships its canonical surfaces as reference moods:

| Mood | Surface | Dial positions |
|---|---|---|
| Monumental | Landing | Monumental, Confident, Sensorial — hero Declaration, frost backdrop, one signature CTA |
| Utilitarian | Telemetry dashboard | Technical, Constrained, Utilitarian — `container-wide`, Technical metrics, coarse grain on mission-critical panels |
| Intimate | Long-form article | Intimate, Human, Inviting — `container-narrow`, Narrator at `leading-loose`, pastels, optional Mode B drop cap |
| Constrained | Settings | Constrained, Utilitarian, Inviting — forms on recessed channels, toggles, no atmosphere |

## Quiet mischief — where play lives

Mischief is always functional play: the delight and the meaning arrive together, and it works only because the straight face is established first.

| Primitive | Mischief | Not mischief |
|---|---|---|
| Color | A brief saturation flare on success; the signature somewhere small and surprising (selection highlight, scrollbar, cursor accent) | Random color, rainbow effects, decorative gradients |
| Space | A pull quote that bleeds into the margin; an image that breaks the column grid — on purpose | Inconsistent margins that make the exception unreadable |
| Material | A hover that shifts finish, as if polished (`CardGlow`); parallax so slight it reads as depth | Glass effects everywhere, gratuitous blur animation |
| Motion | A barely-perceptible overshoot (`ease-hourglass-settle`); a card that tilts ±2deg toward the cursor (`card--tilt`) | Ambient motion that runs when no one is interacting |

## The reference shelf

The instincts the system was distilled from — reach for these when a decision is unclear:

- **Control** (the game) — enormous heavy letters over content; diegetic, stylized, intentional UI.
- **NASA lunar and Mars missions** — hardware designed to be seen by many and meant to inspire; the source of orange-as-urgency.
- **Split-flap displays, mechanical watches, hourglasses** — motion with a visible mechanism.
- **Machined aluminum, Parker pens, LEGO** — manufactured quality you can feel.
- **1960s–80s posters and Art Deco** — limitation that forced intent; the lineage of Declaration Mode B.
- **Terminal user interfaces and Blender's zones** — density that reads as organization; the HUD and the workbench.
- **The rejected:** clutter (strategy-game UIs), the generic LLM-generated look, ornament without function, pastiche.

## Evolution

Amend with intent, not impulse. Not every new preference is a principle — a principle is something that, when violated, makes the work feel wrong.
